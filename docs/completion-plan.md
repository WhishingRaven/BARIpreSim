# Goal 완료까지 남은 작업

현재 요청은 네 행동을 **각각 별도 GRU 모델**로 학습하는 것이다. 새 10,000회
학습을 자동 실행하지 않았으며, 사용자가 README 명령어로 시작한다.

1. 임의 배치에서 학습한 원형·사각형·직선·추종을 고정 개발 seed로 평가한다.
   원형 반지름은 0.5 m, 사각형 한 변은 1 m이며 중앙에 다섯째 로봇이 있어야 한다.
   직선은 다섯 대가 하나의 대열을 이루어야 한다. 형성 후 정지를 허용한다.
2. 여러 학습 seed와 분리된 최종 held-out seed에서 성공률·오차·유지 시간·접촉을
   확인한다. 보상 증가나 학습 코드 검증을 행동 수렴으로 간주하지 않는다.
3. 별도 모델을 선택하는 제어기와 hidden state 처리 규칙을 정하고, 기존 위치·시간·
   센서 이력을 유지하며 12방향 미완료·반복 전환을 검증한다. 같은 hidden 크기만으로
   서로 다른 모델의 hidden을 호환된다고 간주하지 않는다.
4. 검증된 모델로 가림 강도·시점·기간을 고정한 paired seen/unseen 평가와 GRU
   hidden-reset 비교를 수행하고 복구 시간·충돌을 보고한다.
5. 성공한 정책의 연속 3D 시연과 actor-only export를 만든다. 다단계 parity와 실제
   ESP32-S3 전체 펌웨어 peak SRAM·추론 지연·deadline을 PSRAM 없이 측정한다.
6. 실물 수령 후 센서·모터·조향을 교정하고 지름 2 m 아레나를 제작·실측한다.

현재 소프트웨어 변경과 새 보상·경로·GPU 설정은 [학습 문서](training.md), 실제
검증 근거는 [현황](status.md)에 있다. 상위 AGENTS TODO는 미완료다.
[이전 계획](completion-plan-history.md)은 과거 실험 설명으로 보존한다.
