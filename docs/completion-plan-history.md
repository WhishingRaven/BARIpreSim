**Goal 완료 조건과 남은 작업**

목표는 반지름 1 m 아레나에서 다섯 대가 로컬 거리 관측과 GRU 기반 RL로
원·사각형·직선 형성 및 움직이는 리더 추종을 수행하고, 미완료 상태의 작업
전환과 가림을 견디며, ESP32-S3에서 PSRAM 없이 실행되는 것을 증명하는 것이다.
시뮬레이터 실행이나 학습 손실 감소만으로 완료 처리하지 않는다.

| 범위 | 현재 만든 것 / 확인된 것 | 완료까지 필요한 것 |
| --- | --- | --- |
| 시뮬레이터 | 반지름 1 m, 다섯 차동구동 로봇, 몸체·벽 충돌, 여섯 방향 최근접 표면 관측, 센서 지연·잡음, 재현 가능한 기록 | 실제 센서·모터 측정값 반영과 재검증 |
| 학습 | 공유 GRU와 개별 hidden state, recurrent PPO/MAPPO, 체크포인트·정확한 재개, 모방학습 초기화와 데이터 수집 | 무작위 초기 배치에서 네 행동을 수행하는 정책과 여러 독립 학습 seed |
| 현재 학습 성과 | 실제 PPO 50회 후 추종 대열 근처 개발 조건 21/21 성공·최종 유지, 안전 위반 0; 무작위 추종은 0/5 | 일반 초기 배치에서 추종 대열 획득, 원·사각형·직선 획득·유지 |
| 추종 평가 | 익명 대열의 경로·간격을 평가하고 형성된 물리적 순서를 고정해 이후 순서 보존 평가 | 교차·재획득·다른 형성에서 진입하는 조건 검증 |
| 작업 전환 | 다음 제어 단계에 적용, 위치·시간·센서 이력·hidden state 유지, 12방향 전환 계약 검사 | 학습 정책의 12방향 미완료·반복 전환 성공과 연속 시연 |
| 가림·메모리 | 실제 몸체가 다른 몸체의 관측을 가리는 최근접 센싱, 물리·타이밍 probe, hidden-reset 비교 도구 | 같은 검증된 정책으로 가림 강도·시점·지속 시간을 고정한 seen/unseen 비교와 복구 시간·충돌 보고 |
| 시각화 | 두 바퀴·세 층 구조의 3D 관찰 화면, 센서·가림·충돌 표시와 라이브 조작, 실제 추종 RL 궤적 재생 | 실제 창 조작 검증과 네 행동을 이어 수행하는 성공 시연 |
| 배포 | actor-only FP32 C++, 96단계 action/hidden parity; 현재 H64 최대 오차 6.11e-7; H64 ESP32-S3 교차 빌드와 가중치 flash 배치 확인 | 최종 정책의 대상 보드 빌드·device parity·전체 펌웨어 peak RAM·추론 지연·deadline·여유 측정 |
| 실물 준비 | 센서·모터 교정 절차, 2 m 지름 원본·A4 타일 출력 도면과 디지털 검사 | 로봇 교정, 실제 출력·조립·지름 측정, 벽 검출·정지 및 다섯 대 폐루프 시연 |

추가 원형 단계에서 로컬 관측·자기 명령 이력만 쓰는 교사는 무작위 시작
118/128개를 성공·최종 유지했고 안전 위반은 없었다. 같은 데이터·학습량의
일반 GRU와 이전 명령 입력을 제외한 GRU는 모두 0/5였다. 후자는 안전 위반 없이
평균 최종 최대 오차 79 mm로 35 mm 기준에 미달했다. 다음 학습 과제는 이
교사 성능을 학생의 실제 실행 상태에서도 유지하는 GRU로 옮기는 것이다.
당시 고정한 모방학습 단계는 학습량 자동 연장이나 PPO 없이 끝났다.
상세 근거는 [원형 단계 보고서](../reports/local-circle-learning.md)에 있다.

이후 학생 실행 상태 128개를 추가하고 같은 총 학습량으로 비교한 두 GRU와
학습 전용 로컬 중심 추정 보조 손실 후보도 모두 0/5였다.
학생 궤적·교사 라벨 진단과 실패한 후보를
[보강 학습 보고서](../reports/local-circle-student-learning.md)에 보존했다.
교사의 복구 성공이나 보조 손실 감소가 학습 정책의 형성 성공을 뜻하지 않는다.

그 뒤 별도로 계획한 [실제 PPO 원형 교정 실험](../reports/circle-rl-repair.md)은
미검증 초기 정책을 그대로 미검증으로 명시해 사용했다. 200회 update 후 높은
학습률은 1/15개에서 원형을 획득·최종 유지했고, 낮은 학습률은 0/15였다.
성공 사례는 초기 오차 259 mm에서 최종 32.5 mm로 줄고 15 s 유지했지만,
전체 성공률 기준에는 미달한다. 해당 3D 영상은 1/15 진단 사례로 표시했다.

짧은 분기 보상으로 기울기를 추정하는 별도 학습도
[검증](../reports/finite-return-gradient.md)했다. 배우 입력·추론 구조는 유지했지만
두 후보 모두 최종 유지 0/15였다. 한 번의 갱신에서 명령·hidden state가 크게
바뀌는 현상을 측정했으며, 다음에는 갱신 크기를 제한하는 안정성 검증이 필요하다.

후속 [갱신 제한 실험](../reports/finite-return-trust.md)도 고정 80회에서 끝냈다.
기록된 명령·hidden 변화 제한은 전부 지켰지만, 최종 유지 0/15와 접촉 시도
382회로 행동 기준에 미달했다. 갱신 안정성만으로 장기 폐루프 형성과 안전이
해결되지는 않았다. 추가 학습이나 기본 정책 승격 없이 실패 결과를 보존했다.

별도 [자기 명령 이력 진단](../reports/command-model-history.md)에서는 명령으로
이동을 적분하는 전처리를 검증했다. 그러나 기존 hidden state에 추정값 여섯 개를
더한 선형 진단은 중심 오차가 135 mm에서 138 mm로 악화돼 사전 기준에 미달했다.
따라서 조건부 정책 학습은 시작하지 않았다. 이 값은 접촉 때 오차가 누적되는
명목 이동 추정이며 실측 odometry나 실패 원인 확정으로 취급하지 않는다.

그 뒤 [로컬 중심 추정 입력 실험](../reports/local-belief-circle.md)은 거리·자기
명령 이력으로 계산한 가설 중심과 신뢰도를 GRU에 제공했다. 별도 12-field
계약의 모방학습은 1/5개에서 형성·최종 유지를 달성했지만 접촉 시도 511회로
통과하지 못했다. 성공 사례는 초기 206 mm에서 최종 28.8 mm, 유지 26.3 s였다.
기준을 유지해 큰 평가와 RL은 실행하지 않았다. 추정 상태만 호스트에서 로봇당
168,440 B를 사용하므로, 채택하려면 actor와 전체 펌웨어를 포함한 대상 SRAM·
지연 검증이 필요하다. 기본 9-field 정책이나 기존 ESP32 빌드는 바뀌지 않았다.

후속 [교사 데이터 전체 코호트 비교](../reports/local-belief-clean.md)는 초기
가중치와 총 6,400회 갱신을 맞췄다. 교사 128개만 사용한 새 정책은 공식 성공
2/5, 최종 유지 1/5, 접촉 시도 74회였다. 평균 최종 오차는 48 mm로 줄었지만
기준에는 미달했다. 추정기 기억을 유지한 채 GRU hidden만 매 단계 지우면
0/5와 189 mm였다. 이 다섯 개발 사례의 진단을 일반적인 메모리·가림 성능으로
확대 해석하지 않는다. 다음 데이터 실험은 현재 학생의 실제 실행 상태를 새로
수집해 기존 실패 학생 데이터와의 분포 차이를 검증하는 방향이다.

이후 [현재 학생 데이터 보강](../reports/local-belief-current-student.md)에서 새
128개 주행을 교사 개입 없이 수집하고 모든 관측·추정 입력·명령·최종 평가를
정확히 재생했다. 원래 교사 데이터와 합쳐 새로 학습한 정책은 공식 성공 3/5,
최종 유지 2/5, 접촉 시도 213회로 여전히 미달이다. 최종 오차 35.163 mm인
사례도 35 mm 기준대로 실패로 남겼다. 추정 오차 진단은 입력·라벨·가중치나
데이터 필터에 사용하지 않았다. 바퀴 명령 모방만으로 안전한 유지가 해결되지
않았으며, 이 모방학습 단계는 예산 연장 없이 종료했다.

별도로 계획한 [로컬 추정 입력 GRU-PPO 실험](../reports/local-belief-rl.md)에서는
해당 초기 모델을 미검증으로 명시하고 실제 형성·안전 보상만으로 학습했다.
각각 200회 갱신 후 낮은 학습률은 공식 성공·최종 유지 8/15, 접촉 시도 354회,
높은 학습률은 3/15, 426회였다. 사전에 고정한 14/15 및 안전 위반 0 기준에
둘 다 미달해 기본 정책으로 채택하지 않았다. 추정기 상태를 포함한 8개 환경의
저장·재개와 에피소드 경계 재현성은 확인했지만, 행동 수렴의 증명은 아니다.
새 학습량을 자동 추가하거나 중간 모델을 골라 실패 결과를 대체하지 않는다.

이어 [실패 진단과 H128 비교](../reports/local-belief-width128.md)를 수행했다.
초기·최종 PPO 30개 주행을 정확히 재현했고, 신뢰도가 낮은 중심 입력을 0으로
두는 진단은 최종 유지를 8/15에서 5/15로 악화시켜 채택하지 않았다. 같은 전체
데이터·초기 H64 함수·40 epoch 순서·6,400회 갱신을 유지한 H128은 공식 성공과
최종 유지 3/5, 접촉 시도 17회로 기준에 미달했다. 입력과 다섯 대 명령은 전부
정확히 재생되지만, 모방 오차 감소가 네 행동의 RL 수렴을 증명하지는 않는다.
가중치 약 406 KB와 hidden 512 B도 부분 크기일 뿐 SRAM 적합성은 미검증이다.

새 [사각형·직선 로컬 교사 비교](../reports/local-shape-fields.md)는 학습 모델과
분리한 기준 제어기를 추가했다. 사각형은 자기 역할만 중앙/외곽으로 사용하며,
주변 모서리 반환값이 없을 때 제자리 회전하는 감지 동작으로 첫 5/5를 통과했다.
그러나 추가 20개에서는 13/20 성공·최종 유지로 기준에 미달했다. 내부 물체
추정에 따른 대열 벌리기는 완성 형성의 유지까지 악화시켜 채택하지 않았다.
직선은 목표 간격에서도 작동하던 우회력을 없애고 로컬 정렬 응답을 높여 첫
4/4를 통과했지만, 추가 평가 14/20으로 미달했다. 접촉·벽 시도는 모두 0이었다.
실패를 포함한 전체 기록, 순서 변경 불변성, 센서 집계로 인한 관측 손실 증거와
미학습 교사임을 명시한 3D 영상을 보존했다. 두 교사의 18/20 기준이 충족되지
않아 데이터 수집·학습은 시작하지 않았으며, 네 행동의 GRU-RL 요구는 그대로다.

그 뒤 [로컬 물체 가설 입력 실험](../reports/local-geometry.md)은 새 전처리를
추가했다. 실제 위치·ID·가림 대신 거리·자기 명령 이력에서 계산한 익명 물체
가설을 제공하는 별도 24-field GRU다. 독립 C++/Python 연산 비교, 저장·재개,
개별 리셋과 12방향 전환 계약이 통과했고, 기존 256개 주행을 필터 없이 변환했다.
같은 초기 가중치 블록·학습량의 H64 모방학습은 최종 유지 2/5, 접촉·벽 시도 0,
평균 최종 최대 오차 59 mm로 미달했다. 큰 평가나 RL은 진행하지 않았다.
조회표 853,260 B, 작업 버퍼 35,100 B와 추정기 상태 168,440 B는 부분 크기이며,
실제 ESP32-S3의 flash 배치·전체 peak SRAM·추론 지연 검증이 별도로 필요하다.

다음 구현 순서는 사용자 요청대로 행동별 독립 GRU 모델을 학습하고 무작위 시작의
각 행동을 먼저 통과시키는 것이다. 이후 모델 선택과 hidden state 처리 규칙을
정한 뒤, 위치·시간·센서 이력을 유지하는 전환과 가림을 검증해야 한다.
실패한 정책에 대규모 학습을 반복하기 전에 로컬 관측으로 실행 가능한 교사와
실패 원인을 확인한다. 교사 성공·모방학습 성공·실제 RL 성공은 각각 기록한다.
개발 조건 통과 후에는 개발용과 분리한 고정 held-out seed 및 여러 학습 seed로
평가하고, 최종 정책을 내보낸다.

사용자 요청에 따라 [장기 추종 학습](../reports/follow-long.md)을 시작했다.
현재 최선인 PPO50의 actor·critic·optimizer·8개 환경·hidden·RNG를 이어받아
추가 5,000회 PPO 갱신(공동 제어 512만 단계)을 수행한다. 기존 추종 커리큘럼이
거의 정렬된 대열에 한정됐으므로, 다음 에피소드의 시작 배치·방향을 점차 넓히고
최종적으로 무작위 시작 55%, 대열 근처 유지 25%, 중간 난도 20%를 섞는다.
기존 21개 유지 조건과 별도 무작위 개발 15개를 고정 시점마다 함께 평가한다.
실행 중 보고서와 체크포인트를 자동 저장하며, 장기 학습 완료나 실제 성능 향상은
결과가 나오기 전에 선언하지 않는다. 최종 held-out seed는 사용하지 않는다.

추가 요청에 따라 [원형·사각형·직선의 독립 장기 학습](../reports/separate-formations-long.md)도
시작했다. task마다 seed 11·23·47의 독립 모델 세 개씩, 총 아홉 개를 병렬로
학습한다. 각 작업은 GRU64·8개 환경·PPO 5,000회 갱신이며 가중치와 optimizer를
서로 공유하지 않는다. 원형은 다섯 대의 원형 배치, 사각형은 네 꼭짓점과 중앙
한 대, 직선은 다섯 대의 일렬 배치다. 완성 후 정지한 채 형태를 유지해도 성공이다.
다섯 대 전체 오차 35 mm·유지 3 s·충돌/벽 시도 0의 기존 수치 기준은 유지한다.
각 모델은 자기 task만 평가하며, 다른 모델의 hidden을 그대로 넘기는 전환이나
여러 actor를 탑재한 배포 메모리 적합성을 이 학습으로 주장하지 않는다.

현재 마무리한 [조향 출력 준비 단계](../reports/local-steering.md)는 GRU의 세
출력을 일반 좌우 바퀴 명령으로 변환하는 연산, 라벨 재생과 전체 C++ 파이프라인을
검증했다. 새 행동 학습은 아직 시작하지 않았다. 후속 모방학습 스크립트는 준비돼
있으며, 완료 시 고정 개발 기준을 먼저 통과해야 한다. 이 표현의 PPO 연동과 실제
RL 학습도 별도로 남아 있다. 전처리까지 포함한 검증용 ESP32-S3 앱은 PSRAM 없이
교차 빌드됐고, 가중치 108,044 B와 조회표 853,260 B는 flash에 배치됐다.
정적 할당 IRAM 16,384 B / D/IRAM 262,923 B와 앱 크기 1,220,480 B는 실제
peak SRAM·추론 지연·전체 펌웨어 여유 측정과 구분한다. 최종 정책은 아니다.

현재 가정으로 고정한 수치 기준은 형성의 다섯 대 최대 오차 35 mm,
추종 경로·인접 간격 오차 55 mm, 리더 이동 0.3 m 이상, 연속 유지 3 s,
timeout 30 s, 에피소드당 충돌·벽 침범 0, 요구 성공률 90%다.
결과를 본 뒤 기준을 낮추지 않는다. 현재 성공은 가정한 평면 FOV 60°에서 나온
개발 결과다. 기본 center-ray 센싱과 구분하며, 실제 VL53L7CX zone을 여섯 값으로
줄이는 방식과 실측 센서 특성은 아직 확정되지 않았다.

실물 수령 뒤의 MVP로 둔 것은 **센서·모터·조향 교정**과 **실물 아레나 제작**이다.
전체 goal에서 제외한 항목이 아니므로, 해당 실측 전에는 실물 검증 완료를
선언할 수 없다. ESP32-S3의 내부 SRAM 512 KB, PSRAM 금지는 확정됐고,
정확한 보드 변형·flash 용량·제어 주기는 미정이다. actor, 전처리, hidden state,
추론 버퍼 및 필요한 펌웨어 런타임을 모두 포함해 측정해야 한다.
현재 H64 actor의 [ESP32-S3 교차 빌드](../reports/follow-rl50-esp32s3-build.md)는
PSRAM 비활성화와 가중치 103,944 B의 flash 배치를 확인했다. 벤치마크 앱은
348,944 B이며, 정적 IRAM 16,384 B와 D/IRAM 71,259 B를 사용한다. 후자에는
지연 기록용 15,360 B가 포함된다. hidden state는 로봇당 256 B다. 이 수치들은
전체 펌웨어 peak RAM, 동적 런타임 사용량이나 보드 추론 시간의 증명이 아니다.

[관측·동작 계약](contracts.md), [실물 측정 계획](../hardware/README.md)에 있다.
